# Digital Design
전자공학 전공 학습을 위한 Verilog HDL 및 디지털 회로 설계 저장소입니다.

기초 논리회로 구현부터 순차회로 설계, 디지털 시스템 프로젝트까지 학습 과정을 기록합니다.

## 📂 Directory Structure
```text
Digital_Design/
├── Agent/          # RTL Verification AI Agent (Python + LLM + Vivado xsim 기반 검증 자동화)
│   └── ...
├── Fundamentals/   # 기초 논리회로 및 Verilog HDL 학습 (조합회로, 순차회로 등)
│   └── ...
├── Projects/       # 디지털 시스템 설계 프로젝트 (UART, SPI, FIFO, I2C 등)
│   └── ...
├── .gitignore
└── README.md
```

## 🛠 Development Environment
- Language : Verilog HDL
- Editor : Antigravity IDE (VS Code)
- FPGA Design Tool : Vivado 2024.2
